# AmneziaWG 3.1 and React Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Track checks here and in the plan's local ledger.

**Goal:** Deliver AWG 3.1, consistent IPv4/Yandex profiles, and the approved React admin redesign.
**Architecture:** Retain Node management APIs and persisted client identities. Introduce a versioned AWG 3.1 validator/migration and replace Vue with focused React components and hooks.
**Tech Stack:** Node, AWG Go 3.1, React/React DOM latest stable, Vite, Vitest, Testing Library, CSS, local React Bits components.
**Spec:** `docs/superpowers/specs/2026-11-03-awg31-react-design.md` (approved by user).

## Global Constraints

- One shared IPv4 profile for all devices; DNS `77.88.8.8, 77.88.8.1`, MTU `1280`; explicit overrides remain supported.
- Preserve identities, tags, quotas, expiry, links, audit, backups, translations and optional UI settings.
- Persist `protocolVersion: "3.1"`; exclusive versioned backups; no parameter regeneration after migration.
- Cloud-white, sky blue and red palette; usable at 360px and with keyboard/reduced motion.
- No remote deployment, release publishing, or modifications to the running VPN.

## Review Focus

- Existing v2 files with metadata and unknown versions: migrate without data loss or unwanted writes (Task 1).
- Existing server env values and blank DNS: overrides must win consistently for downloads and QR (Task 2).
- Long names, zero traffic and no handshake: search and connection states stay accurate (Task 3).
- Late requests after logout and slow polling: no stale clients or overlapping polls (Task 3).
- Partial API failures, no private key, expired quota and mobile dialogs: visible errors and retained functionality (Task 4).
